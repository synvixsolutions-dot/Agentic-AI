# Agentic AI Club — Combined Team Project

This folder combines the current team work into one static website.

## Page ownership / sources
- `index.html` — current Home design
- `about.html` — current About design
- `events.html` — teammate Events page
- `projects.html` — teammate Projects page
- `join.html` — teammate Join page
- `blog.html` — Kabilan Blog page
- `contact.html` — Kabilan Contact page

## Main stack
- HTML
- CSS
- Vanilla JavaScript
- IBM Plex Sans / IBM Plex Mono for the main team pages

## Files
- `css/club.css` + `js/club.js` — main team site
- `css/kabilan-style.css` + `js/kabilan-main.js` — preserved Blog/Contact implementation

The Home hero is centered (no side-by-side split) and section spacing has been reduced in the Home/About design.

Open `index.html` to start.

Blog and Contact now use the same shared `css/club.css` and `js/club.js` visual system as the rest of the website while preserving their original page content.
